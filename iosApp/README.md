# iosApp/

Native iOS app built with SwiftUI, targeting iOS 17+.

## Setup

```bash
# 1. Install XcodeGen
brew install xcodegen

# 2. Create config files (gitignored)
mkdir -p Config
# Create Config/Production.xcconfig and Config/Staging.xcconfig
# See docs/ENVIRONMENTS.md for the required keys

# 3. Generate Xcode project
xcodegen generate
# or from repo root: make ios-project

# 4. Build the shared framework
cd .. && ./gradlew :shared:linkDebugFrameworkIosSimulatorArm64

# 5. Open in Xcode
open Strakk.xcodeproj
```

## Architecture

- **Views**: SwiftUI views organized by feature (`Today/`, `Meal/`, `CheckIn/`, etc.)
- **ViewModel wrappers**: `@Observable` classes that wrap shared KMP ViewModels via SKIE
- **Theme**: `Theme/` contains colors, typography, and reusable components per `DESIGN.md`
- **No business logic**: all logic lives in `shared/` — Swift views only handle UI

## Schemes

Two schemes are available after `xcodegen generate`:

| Scheme | Bundle ID | Description |
|--------|-----------|-------------|
| Strakk | `com.strakk.Strakk` | Production |
| Strakk Staging | `com.strakk.Strakk.staging` | Staging (separate app on device) |

The pre-build script automatically passes `-Penv` to Gradle based on the active scheme.

## Localization

- Source language is English in code: `Text("Start now")`
- Xcode auto-extracts to `Localizable.xcstrings` (String Catalog)
- French translations are added in the String Catalog under `fr`
- Use `String(localized:)` for programmatic strings

## Linting

```bash
# SwiftLint (local only, no macOS CI runner)
make lint-swift
# Config: .swiftlint.yml
```

## Project generation

The Xcode project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml`. The generated `Strakk.xcodeproj/` is gitignored. Always run `xcodegen generate` after pulling changes.

## Requirements

- macOS with Xcode 15+
- XcodeGen (`brew install xcodegen`)
- JDK 17+ (for building the shared framework)
